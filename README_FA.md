# اسکنر شبکهٔ Wi-Fi

[English guide](README.md)

ابزار محلی کوچکی بر پایهٔ یکی از تمرین‌های قبلی Wi-Fi که نام شبکه‌های قابل مشاهده و قدرت سیگنال را از نخستین رابط بی‌سیم نشان می‌دهد. به شبکه وصل نمی‌شود، گذرواژه امتحان نمی‌کند و اطلاعات ورود جمع‌آوری نمی‌کند.

روی رایانهٔ دارای کارت Wi-Fi سازگار اجرا کنید:

```bash
pip install -r requirements.txt
python scanner.py
```

اگر کارت شبکه دیرتر پاسخ می‌دهد، `--wait 4` را اضافه کنید. اجرای واقعی با کارت فیزیکی در محیط آماده‌سازی بررسی نشده است. بخش حدس و چاپ گذرواژهٔ فایل اولیه عمداً حذف شده است. مجوز MIT.
